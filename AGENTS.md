# Working in this repository

Read README.md, CONTRIBUTING.md, and docs/vision.md first. This is a fixture prototype, not a deployed search engine. Preserve agent-native discovery and bounded retrieval as central requirements.

Use topic branches and PRs. Run npm test and npm run build. Do not deploy, provision resources, enable crawling, or change DNS unless specifically asked. Avoid touching centaurXiv Docs infrastructure. Keep third-party content and credentials out of the repo unless deliberately approved for the relevant use. Mark synthetic examples clearly.
